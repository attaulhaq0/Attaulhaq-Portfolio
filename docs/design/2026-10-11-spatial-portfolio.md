# Personal spatial portfolio

The owner requested a dramatic portfolio close to the supplied figurative 3D inspiration, replacing the previous mint editorial direction. The owner authorized implementation and preview, Microsoft Foundry Sunburst 2.5 / Sora 2 generation, and installations on G:. The supplied frontal headshot is the primary likeness reference; QSTP full-body photography supplies clothing context.

## Visual direction

Near-black plum stage, soft lavender rim light, pale typography, restrained pink highlights. A central seated personal avatar and workstation sits between compact identity at left and large Developer / Product Builder typography at right. The hero occupies the first viewport. A quiet header and bottom metadata frame it. Original code implements the reference's composition principles without redistributing its restricted models or trial plugins.

The page continues through a short personal introduction, an open numbered project showcase, approach, biography/experience, real event photos and immersive education footage, then oversized contact. All sections use the same dark palette and generous spacing. Existing five case-study URLs and honest content remain.

## Implementation

- Hero: static personal poster, optional generated motion, explicit 3D control and safe cleanup.
- PersonalAvatar / SystemScene: original photo-informed mesh avatar with a narrow camera, lavender lighting, pointer response, reduced-motion handling, visibility suspension and disposal.
- Redesign styles / tokens: coherent layout, typography, responsive behavior and dark case-study theme.
- FieldNotes / moments: approved QSTP, Google Cloud and Coffee & Community photos plus a separate immersive education video.
- Foundry generation artifacts remain under output; optimized consuming media lives in public. Credentials never enter page code or manifests.
