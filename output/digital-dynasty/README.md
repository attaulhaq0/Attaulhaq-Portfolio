# Digital Dynasty — actual prototype media

The original owner-supplied recording remains at its source path, unchanged. The public video is a 60-second edited, deliberately silent excerpt from this recording. Its original audio stream has been removed; this does not claim the source was silent.

The footage shows prototype gameplay, test arenas and Unreal Engine play-in-editor demonstrations. All source UI, overlays and prototype labels remain visible. No generated scene or product visualization appears in these exports.

Exact source hash, selected intervals, output encoding, screenshot timestamps and filenames are recorded in media-manifest.json.

Regenerate with:

    node scripts/process-digital-dynasty.mjs

The local ffmpeg binary location is explicitly defined in the script.
